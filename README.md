## 为网页版 Apple Music 提供歌词翻译，数据来源为网易云音乐。
在 [greasyfork](https://greasyfork.org/zh-CN/scripts/493948-apple-music-%E6%AD%8C%E8%AF%8D%E5%A2%9E%E5%BC%BA) 安装

***
### 更新记录
v1.3
1. 支持随设备切换深色模式；
2. 若歌词匹配错误或未找到歌词，现在可以手动查找并保存选择；
3. 若歌曲歌词未翻译，现在可以调用浏览器自动翻译并保存；

（注：翻译功能是本机浏览器自带的 Translator API，它的翻译模型在设备本地运行，仅限 Chrome 与 Edge 浏览器）

4. 听歌统计与一些设置。

<hr>

v1.2 支持微调并存储每首歌曲的歌词偏移时间



***

### 特性
1. 带翻译的滚动歌词，支持用机翻补充缺失翻译的歌词；
2. 自动匹配歌词，若匹配失败可以手动搜索匹配；
3. 统计一周听了多久音乐；
4. 随设备切换深色模式；

### 安装方法
1. 点击安装，然后打开 music.apple.com，随便点击一首歌播放；
2. 此时可能会跳出“一个用户脚本试图访问跨源资源”的窗口，请选择“总是允许”，
这是为了访问 music.163.com 网易云音乐的 API，你可以看见页面上的提示信息，不存在恶意请求。
